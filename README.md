### Comment je travaille

Next.js, React, TypeScript et Tailwind, exportés en fichiers statiques et servis par le
réseau Cloudflare. Pas de base de données, pas d'extension qui se périme, aucun cookie
déposé — donc aucun bandeau de consentement à imposer aux visiteurs.

Plusieurs directions artistiques sont proposées avant la première ligne de code. Le site
n'est développé qu'une fois la direction choisie.
